# 项目复盘：AI营销 Agent 达人投放推荐工具

## 项目目标

本项目面向品牌达人投放场景，解决达人筛选效率低、推荐依据不透明、内容建议依赖经验、投后复盘不系统的问题。

第一版目标不是训练复杂模型，而是做出一个业务流程完整、推荐逻辑可解释、可稳定演示的 AI Agent MVP。

## 用户场景

品牌运营或内容运营需要为一款美妆护肤新品选择达人。用户输入品类、目标人群、预算、平台、投放目的和产品卖点后，系统推荐合适达人，并生成推荐理由、内容脚本方向和投后复盘摘要。

## 核心方案

项目流程为：

```text
品牌目标输入 → 达人匹配推荐 → AI 推荐理由与内容建议 → 投放复盘分析
```

推荐排序由规则模型负责，保证结果可解释；AI 生成模块负责把推荐依据转成运营人员可读的理由、内容方向和复盘建议。

## 推荐规则

推荐分综合以下维度：

- 标签匹配：达人领域与产品品类、关键词、卖点的匹配程度。
- 受众匹配：达人粉丝画像与品牌目标人群的重合程度。
- 内容效果：互动率和平均播放量。
- 成本效率：报价与单人预算的适配程度。
- 历史转化：历史转化率和历史 ROI。
- 品牌安全：达人内容稳定性和风险控制。

不同投放目标下，权重会动态调整。例如曝光目标更看重内容效果，转化目标更看重历史 ROI，种草目标更看重标签和受众匹配。

## AI 模块

AI 模块包含三类输出：

- 达人推荐理由：解释为什么推荐该达人。
- 内容建议：生成标题、脚本框架、卖点表达和风险提示。
- 投放复盘摘要：总结表现最好/最弱的达人，并给出下一轮优化方向。

系统默认使用模板 fallback，因此没有 API Key 也能完整演示；配置 API Key 后可切换真实 LLM 调用。

## 复盘指标

投放复盘使用以下指标：

- CTR = 点击量 / 曝光量
- CVR = 转化量 / 点击量
- CPM = 花费 / 曝光量 * 1000
- CPC = 花费 / 点击量
- CPA = 花费 / 转化量
- ROI = 收入 / 花费

复盘页面会展示整体指标、达人表现对比、ROI 排名和转化漏斗。

## 项目不足

- 当前数据为合成样例数据，尚未接入真实平台数据。
- 推荐权重基于业务规则设定，尚未用真实投放效果训练或校准。
- 第一版以单行业美妆护肤为主，多行业标签体系仍需扩展。

## 后续优化

- 接入真实达人数据或手工整理真实案例。
- 增加 A/B 内容策略建议。
- 引入多轮 Agent 对话，让用户可以要求系统解释、重排或调参。
- 用真实投放复盘数据优化推荐权重。
